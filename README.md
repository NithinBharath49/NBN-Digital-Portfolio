# NBN Digital Services — Portfolio Website

A responsive static portfolio website built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and project sections
- `style.css` — layout, colours, responsive design and project visuals
- `script.js` — mobile navigation and automatic copyright year

## Run locally
1. Extract the ZIP.
2. Open the `NBN-Digital-Portfolio` folder in VS Code.
3. Open `index.html` in your browser (or use the VS Code Live Server extension).

## Before publishing
1. Replace `hello@nbndigital.online` in `index.html` if you use another email.
2. Replace concept projects with your real project descriptions and deployed demo links when ready.
3. Add your GitHub and LinkedIn links if you want them shown.
4. Test on mobile and desktop.

## Important
The four project cards are labelled as concepts / in development. They are visual portfolio placeholders, not completed live applications. The contact email is a placeholder until you confirm it is active.
